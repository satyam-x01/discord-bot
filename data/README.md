# Local profanity terms

`profanity-terms.txt` contains 82,782 unique terms extracted from the `word` and `transliteration` fields of the [ProfanityBench dataset](https://github.com/NileshArnaiya/ProfanityBench/tree/master/data). The extraction included entries marked `safe_for_work: false` and lowercased and deduplicated them. This is a large multilingual reference list, not a guarantee of every profanity or slang term. Entries can be ambiguous or inaccurate, so expect some false positives.
